# PAIMANA April 2026 dataset

Source: MoSPI/IPMD PAIMANA Flash Report, April 2026.

The imported registry contains 1,981 project records from the report's All Ongoing Projects table. The parsed financial totals are:
- Original cost: Rs. 3,712,662.01 crore
- Revised cost: Rs. 4,278,402.37 crore
- Cumulative expenditure: Rs. 2,036,107.49 crore

These totals reconcile to the report's portfolio totals. The dataset is a single monthly snapshot; it does not contain independent historical outcome labels, so the application must not claim a measured ML accuracy percentage from this file alone.
